# Tahap 3: CRUD di memori

Proyek mandiri ini melanjutkan tahap 2 dengan operasi create, read, update,
dan delete (CRUD). Data disimpan dalam `Vec<Laptop>`, bukan database, sehingga
akan hilang ketika program ditutup.

Jalankan dengan `cargo run`. Tahap berikutnya mempertahankan operasi CRUD
tetapi menyimpan data di PostgreSQL.
